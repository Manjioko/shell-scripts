# 无人值守开工检查表

**触发条件**:准备执行 `wchat -auto …` / `-st …`,或你正准备在 auto 会话里做一个"写完就退、没人看屏"的任务。

本项目出过一次这样的事故:auto 的会话工作根是 `$HOME`,相对路径写入真的成功了,只是落在 `~/.scratch` 下;回显只有相对路径,于是下一轮"文件不存在",人以为文件被删。**根因不是 bug,是没人确认过"这次的工作根是哪个目录"。** 这张表就是防这一类。

## 六项,顺序做

```bash
pwd                       # 1 你要它在哪儿干活
echo "$WORK_ROOT"         #    (会话内)程序认定的工作根 = 进程启动时的目录,与后续 cd 无关
```
1. **工作根对不对**。`WORK_ROOT` 由**进程启动目录**决定,你在会话里 `cd` 不会改变它。`WORK_ROOT=$HOME` 意味着"工作目录内"这个前提几乎恒真 ⇒ 沙箱边界实际等于整个家目录。要收窄:`cd` 到项目目录再起进程。
2. **档位**。`-auto=read`(只放越界读)/ `sandbox`(默认,工作目录内全自动、越界写拒)/ `full`(再加 `--allow-write` 名单)。**档位与承诺不符是这个项目反复出事的形状** —— 别凭记忆,看启动时打印的能力清单。
3. **白名单是否够用**。越界写要 `-auto=full` **且** `--allow-write <路径>`(路径会被归一化后入名单)。名单是**启动时一次批好**的,模型不能半路自己加 —— 这是设计,不是不便。
4. **安装授权**。默认 H14 一律拒。要装东西:重启加 `--allow-install 包名1,包名2`(只点你认识的名字,配额默认 5 次/会话)。**不带包名 = 全开**,签名清单里会带 ⚠ 警告;换源形状有授权也拒。
5. **回滚点**。启动横幅 `回滚点: git …` 或 `rsync 快照 → …`。没有回滚点 ⇒ 非 read 档会被降级为 read。**看到"工作树有未提交改动"警告就先 commit**,否则回滚会连带丢掉你自己的改动。
6. **刹车参数确认过一眼**:

| 参数 | 默认 | 含义 |
|---|---|---|
| `MAX_TOOL_ROUNDS` | 250 | 单轮工具调用上限,撞顶强制停 |
| `CMD_TIMEOUT` | 120 | 单命令墙钟 |
| `AUTO_MAX_APPROVALS` | 200 | 每会话自动放行配额,超了退回人工 |
| `AUTO_DENY_STREAK` | 3 | 连续被拒 N 次 ⇒ 本轮降级人工 |
| `AUTO_MAX_WRITES_PER_PATH` | 8 | 同一绝对路径单会话写满即熔断(只拒该次) |
| `AUTO_MAX_INSTALLS` | 5 | 每会话安装次数 |
| `TOKEN_THRESHOLD` | 窗口×3/4 | 压缩点;想省 token 用 env 调小 |

## 两个容易漏的
- **改过 wchat.sh 必须重启进程**。代码是装载进内存的,盘上改了判据对老会话无效;新版会在运行期检测到判据文件变更时**主动退回人工**(审计行 `pol` 字段 = 该会话生效的版本)。
- **无人值守一次性任务**没有 tty 时要用 `WCHAT_AUTO_ASSUME_YES=1` 显式代替签字,这条会被记进审计。别用管道喂 stdin 假装签过。

## 收尾必做
看 `auto_report_exit` 打印的小结:自动放行次数 / 备份份数 / 回滚命令 / 审计路径。然后至少扫一眼审计:
```bash
grep -o '"rule":"[^"]*"' ~/.ct/auto/audit.log | sort | uniq -c | sort -rn | head
```
`F1`(路径熔断)、`S1`(判据自检)、`H14`(安装)这几类非零,都说明任务里发生了"本该由你决定"的事。
